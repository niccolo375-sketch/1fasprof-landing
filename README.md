# ФасПроф — обновлённый лендинг

Содержимое: `index.html`, `assets/` (фотографии автомобилей), `api/lead.js` (отправка заявок в Telegram).

Переменные Vercel оставить прежними: `TELEGRAM_BOT_TOKEN`, `TELEGRAM_CHAT_ID`. Форма отправляет имя и телефон, поле города удалено. Endpoint `/api/lead` сохранён.

Для обновления замените `index.html` и `api/lead.js` в корне GitHub-репозитория и добавьте папку `assets`, затем сделайте commit. Vercel автоматически соберёт новую версию.
