# ФасПроф — лендинг для набора водителей

## Что входит
- Адаптивная одностраничная страница на русском языке.
- Форма заявки: имя, телефон, город.
- Серверная функция `/api/lead`, отправляющая заявку в Telegram.
- Токен бота хранится только в переменных окружения Vercel, не в браузере.

## Настройка перед публикацией
1. Создайте проект на Vercel и загрузите содержимое этой папки в GitHub или через доступный способ импорта.
2. В настройках проекта Vercel → Settings → Environment Variables добавьте:
   - `TELEGRAM_BOT_TOKEN` — токен от BotFather.
   - `TELEGRAM_CHAT_ID` — ваш числовой Chat ID.
3. Выполните Redeploy после добавления переменных.
4. Отправьте тестовую заявку с сайта и проверьте Telegram.

## Важно
- Сейчас заявки отправляются в Telegram. Постоянное хранение заявок в Google Sheets/CRM ещё не подключено.
- Перед публикацией добавьте полноценную политику обработки персональных данных и проверьте соответствие требованиям законодательства Беларуси.
- Уточните точное коммерческое название модели «Ханси» и условия, связанные с формулировкой «до 50% выручки».
- Не публикуйте токен бота и не вставляйте его в HTML/JavaScript сайта.
